# بازطراحی UI/UX — بستهٔ اول

> ادامهٔ اجرا: [بستهٔ دوم، جست‌وجو و کارت محصول](search/README.md) نیز پیاده‌سازی و بررسی شده است. این گزارش شواهد بستهٔ اول را نگه می‌دارد.

تاریخ: 2026-10-22 — ۱۴۰۵/۰۷/۳۰

دامنهٔ تحویل: هویت بصری پایه، پوستهٔ مشترک، خانه، ناوبری و هماهنگی نوارهای انتخاب. بازطراحی اختصاصی صفحه‌های داخلی در بسته‌های بعدی انجام می‌شود.

## تغییرهای قابل مشاهده

- هویت سبزآبی عمیق و لهجهٔ سبز روشن، سطح‌های خنثی و تم تاریک هماهنگ.
- خانه با جست‌وجوی اصلی، مسیر مکمل انتخاب با راهنما، دسته‌های نیاز و معرفی فشردهٔ مراحل.
- نمایش مسیر خرید در دسکتاپ با عناصر HTML؛ بدون تصویر یا محتوای فروشگاهی ساختگی.
- ناوبری موبایل: خانه، جست‌وجو، راهنما، دستیار، خریدهای من.
- مقایسهٔ محصول و فروشنده از مسیرهای مرتبط و پیوندهای فوتر در دسترس‌اند؛ مقایسهٔ فروشنده در هدر دسکتاپ هم هست.
- اطلاع‌رسانی عمومی کوتاه‌تر؛ هشدارهای مرتبط با قیمت، موجودی و منشأ در صفحه‌های داخلی حفظ شده‌اند.
- بهبود Button، Card، PageHeader و ورودی‌های مشترک؛ ورودی مشترک موبایل ۱۶px است.
- سبد مقایسه به‌صورت فشرده شروع می‌شود و فهرست انتخاب‌ها با دکمه باز می‌شود.
- ارتفاع واقعی سبد با ResizeObserver اندازه‌گیری می‌شود؛ فضای آن در محتوا و نوارهای انتخاب فروشنده لحاظ می‌شود.
- ویژگی `overflow-x: hidden` از body حذف شده؛ تست سرریز دیگر به پنهان‌سازی عمومی متکی نیست.
- نام قابل دسترس فیلد جست‌وجو به label نمایان مرتبط شده؛ جست‌وجو فرم GET عادی و مستقل از JavaScript است.

تست مرورگر نهایی:

```bash
SMOKE_BASE_URL=http://127.0.0.1:3111 npm run test:e2e -- \
  e2e/redesign-shell.spec.ts \
  e2e/smoke.spec.ts \
  e2e/title-nav.spec.ts \
  e2e/a11y-routes.spec.ts \
  --workers=2
```

این فرمان به سرور build تولیدی در نشانی مشخص‌شده نیاز دارد. `SMOKE_BASE_URL` در پیکربندی فعلی پروژه، اجرای build/server خودکار Playwright را غیرفعال می‌کند.

تست تازهٔ پایدار در [redesign-shell.spec.ts](../../../e2e/redesign-shell.spec.ts) ثبت شده است. تست‌های قدیمی ناوبری با مقصدها و برچسب‌های جدید هماهنگ شده‌اند؛ معیار title/route announcer ضعیف نشده است.

## دادهٔ بررسی تکمیلی

دیتابیس واقعی پروژه در workspace موجود نیست. دو دیتابیس جدا و ignoreشده برای QA ساخته شدند:

- `data/fixture.sqlite`: واردسازی مستقیم fixture موجود پروژه.
- `data/ui-qa.sqlite`: همان شش محصول، شش فروشگاه و ۲۱ پیشنهاد مصنوعی، با شناسه‌های هش‌شدهٔ سازگار با اعتبارسنجی URL صفحه‌ها. فایل‌های CSV اصلی تغییر نکردند.

سرور بررسی داده‌دار از `DATABASE_PATH=data/ui-qa.sqlite` استفاده کرد؛ دیتابیس پیش‌فرض `data/app.sqlite` ساخته یا جایگزین نشد. نتیجهٔ این بررسی جای تست روی دیتاست واقعی را نمی‌گیرد و skippedهای وابسته به دیتاست واقعی همچنان skipped گزارش شده‌اند.

مسیرهای بررسی‌شده با داده: جست‌وجو، راهنما، محصول، فروشندگان، فروشگاه، دو مقایسه، پرسش و ماموریت؛ هرکدام در ۳۹۰/۱۴۴۰ و روشن/تاریک. [نتایج و اندازه‌های نوارها](fixture-check.json).

چند تصویر داده‌دار برای کنترل اثر پوسته و رنگ‌ها؛ این صفحه‌ها هنوز طراحی اختصاصی بستهٔ جدید را نگرفته‌اند:

## محدودیت‌ها و مسائل محیط

- نصب وابستگی‌ها از lockfile با کمک کش محلی انجام شد؛ `package.json` و lockfile تغییر نکردند.
- راهنماهای CSS، layout، Link و usePathname از بستهٔ Next 16.4.2 خوانده شدند.
- build پیش‌فرض Turbopack، قبل و بعد از تغییر رابط، در پردازش CSS با خطای محیطی `binding to a port / EPERM` متوقف شد. build رسمی Webpack موفق است؛ تنظیم پیش‌فرض پروژه برای پنهان‌کردن این محدودیت عوض نشده است.
- آزمون اولیه روی dev شکست نام قابل دسترس جست‌وجو را آشکار کرد و اصلاح شد. route announcer روی build تولیدی، با همان معیار تست قبلی، موفق است.
- مرورگر آزمون Chrome است؛ Safari/Firefox، گوشی واقعی، صفحه‌خوان و کاربر انسانی تأیید نشده‌اند.
- آزمون performance میدانی، LCP/INP و صحت دادهٔ واقعی در این بسته انجام نشده است.
