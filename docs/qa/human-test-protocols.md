# پروتکل‌های آزمون انسانی (فاز ۱۰A، Gate D) — **اجرا نشده؛ فقط انسان می‌تواند PASS بدهد**

> عامل کدنویس صفحه‌خوان، گوشی واقعی یا کیبورد مجازی واقعی ندارد. تا وقتی این جدول‌ها پر نشده‌اند: صفحه‌خوان = **NOT VERIFIED**، گوشی واقعی = **NOT VERIFIED**. اسکن axe و آزمون‌های Chromium **انطباق WCAG** را ثابت نمی‌کنند و چنین ادعایی نمی‌شود.
> آماده‌سازی: `npm run build && npm run start` (یا Docker) با `AGENT_PROVIDER=mock`؛ تب خصوصی؛ زبان رابط فارسی. هر ردیف: ✅ / ❌ + یادداشت. هر ❌ را با دستگاه، نسخهٔ مرورگر/صفحه‌خوان ثبت کنید.

## ج) Firefox / WebKit — **دانلود تأیید نشده؛ دستورها فقط پیشنهاد**
| مورد | مقدار |
|---|---|
| وضعیت | NOT VERIFIED (نه Firefox و نه WebKit از Playwright نصب است) |
| اندازه (HEAD در فاز ۹.۱) | Firefox ≈ ۱۱۶٫۴ MB · WebKit ≈ ۱۰۸٫۱ MB · ffmpeg ≈ ۲٫۳ MB؛ دیسک پس از باز کردن ≈ ۲–۳ برابر؛ مسیر `~/.cache/ms-playwright` |
| دستورها (اجرا نشد) | `npx playwright install firefox webkit` ؛ سپس در صورت نیاز `sudo npx playwright install-deps firefox webkit` (نصب سیستمی Fedora ⇒ تأیید جدا؛ Playwright ممکن است بسته‌های GTK/gstreamer/woff2/… را بخواهد) |
| پیکربندی | افزودن دو project (`firefox`، `webkit`) به `playwright.config.ts` (فعلاً فقط Chrome سیستمی) |
| انتخاب تست | `e2e/smoke.spec.ts`، `release-journey.spec.ts`، `title-nav.spec.ts`، `a11y-routes.spec.ts`، `keyboard.spec.ts`، `security.spec.ts` (نه کل ۳۸۰ تست) |
| ریسک شناخته‌شده | WebKit روی Fedora ممکن است کتابخانهٔ کم داشته باشد؛ `style-src-attr` و `Intl` فارسی و `datetime-local` در موتورها فرق دارند؛ قرمز = یافته، نه ادعای سبز |
| جایگزین بدون دانلود | آزمون دستی روی Firefox/Safari نصب‌شدهٔ مالک با فهرست الف/ب |
